# Skill: opera-cli Browser Automation

`opera-cli` controls a Chrome browser session for web automation and inspection. Use it for navigation, interaction, screenshots, tab management, JS evaluation, emulation, DevTools debugging, and performance auditing.

Run `opera-cli --help` for top-level usage, or `opera-cli <command> --help` for command-specific flags and examples.

```bash
opera-cli open https://example.com   # start here — navigate and snapshot the page
```
