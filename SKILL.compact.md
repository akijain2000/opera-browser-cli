# Skill: opera-cli Browser Automation

`opera-cli` controls a Chrome or **Opera Neon** browser session.

- **Standard commands** (`open`, `click`, `fill`, `screenshot`, etc.) — work with any Chrome/Chromium session.
- **Opera AI commands** (`chat`, `invoke-do`, `make`, `research`) — require **Opera Neon** with an active sign-in.

Run `opera-cli --help` for the full command list, or `opera-cli <command> --help` for per-command flags and examples.

```bash
opera-cli open https://example.com   # start here — navigate and snapshot the page
```
